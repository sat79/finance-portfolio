# Validation reports

See [validation evidence](../docs/validation.md) and the [reconciliation register](../docs/reconciliation.csv).

Generated analyst exports belong in ignored `exports/` or a user-chosen output directory. The reconciliation register and a small frozen numerical test fixture retain the verified sample; whole SEC filings and complete API datasets are not bundled. This directory also preserves the portfolio check runner's `src/tests/data/reports` structure convention.
